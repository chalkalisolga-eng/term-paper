# Universal Meteorological Analyzer (Універсальний Аналізатор Погоди)

Програмний комплекс призначений для автоматизації процесів збору, аналізу та зберігання метеорологічної інформації з будь-якої точки планети. Проєкт розроблено в межах курсової роботи з дисципліни "Програмування, алгоритмізація та основи промпт-інжинірингу".

## 🚀 Основний функціонал та архітектура (ООП)

* **Універсальна інтеграція API та Менеджери контексту:** Автоматичне завантаження актуальної погоди для будь-якого міста світу через Open-Meteo API. Безпека з'єднання забезпечується власним менеджером контексту (`with SatelliteConnection`).
* **Моделювання даних та Інкапсуляція:** Використання `dataclass` для базових записів, перелічуваних типів (`Enum`) для опадів, а також захист стану об'єктів за допомогою `@property` та `@setter` із вбудованою логікою валідації.
* **Наслідування та Поліморфізм:** Реалізовано ієрархію аналітичних звітів (базовий клас `Report` та його нащадки `DailyForecast`, `MonthlyReport` з перевизначенням методів генерації інформації).
* **Магічні методи та Ітератори:** Перевизначення методів порівняння (`__lt__`) для сортування записів за температурою, `__getitem__` для пошуку за індексом, а також створення власного генератора `SeasonIterator` для кастомного обходу колекції (наприклад, вибірка лише літніх записів).
* **Комплексна серіалізація даних:**
  * Збереження та відновлення повного стану об'єктів системи у бінарний файл за допомогою `pickle`.
  * Двостороння взаємодія з табличними даними: імпорт вхідних даних та експорт аналітичних звітів у формат `CSV`.
  * Збереження конфігурації та налаштувань застосунку у `JSON`.
* **Відмовостійкий CLI-інтерфейс:** Зручне текстове меню на базі оператора `match/case` з глобальним перехопленням винятків (`try...except`), що унеможливлює аварійне завершення програми при некоректному введенні (Fault Tolerance).

## 🛠️ Вимоги до середовища

Для запуску проєкту та збирання пакунка необхідне наступне програмне забезпечення:

* Python версії 3.10 або новішої.
* Інструмент збирання setuptools (вбудований у сучасні версії Python) або менеджер пакунків pip.

## 📦 Встановлення та розгортання проєкту

1. Клонуйте репозиторій із вихідним кодом на свій локальний комп'ютер: 
   `git clone https://github.com/chalkalisolga-eng/term-paper.git` та перейдіть у папку: `cd meteo-analyzer`
2. Перевірте наявність або створіть базовий конфігураційний файл `config.json` у кореневій директорії проєкту: 
   `{ "app_name": "MeteoAnalyzer", "version": "1.0" }`
3. Встановіть проєкт у локальне середовище в режимі розробки за допомогою конфігурації `pyproject.toml`: 
   `pip install -e .`

## 🎮 Запуск програми

Для старту консольного інтерфейсу та початку взаємодії з системою виконайте команду: `python main.py`
